Проект на тему "Алгоритмы кластеризации K-Means++"
Это учебный проект на языке C.
В нем реализован алгоритм кластеризации K-means со встроенной интеллектуальной инициализацией центроидов K-means++ в виде модульной библиотечной функции.
Программа также считает метрики качества разбиения (WCSS,
Силуэтный коэффициент и индекс Дэвиса-Болдина),
чтобы оценить точность результата.
Основная цель проекта — продемонстрировать работоспособность алгоритма на синтетическом датасете и сравнить полученное распределение с истинными метками.

Что умеет программа:
Программа может принимать сгенерированные точки через стандартный ввод терминала (stdin),
выполнять кластеризацию на чистом Си без сторонних библиотек,
рассчитывать оптимальное количество кластеров методом локтя,
выводить оценку качества по трем метрикам,
а также передавать данные в Python-скрипт для параллельной визуализации эталона и результата.

Основы алгоритмов:
K-Means++: В отличие от стандартного K-Means со случайным выбором центров,
здесь первый центроид выбирается случайно,
а каждый следующий — с вероятностью,
пропорциональной квадрату расстояния до уже выбранных центров.
Это исключает проблему неудачного старта и ускоряет сходимость.

Метод локтя (Elbow Method): Программа автоматически запускает кластеризацию последовательно для разного числа кластеров (от 1 до 10) и считает инерцию (WCSS).
Оптимальное число кластеров находится в точке резкого излома ("локтя") полученного графика.

Пример запуска:
Взаимодействие со скомпилированным Си-ядром полностью автоматизировано через Python.

После запуска программа попросит ввести в консоль количество точек,
число кластеров и лимит итераций.

Сборка:
Для сборки нужен компилятор GCC и утилита Make.
Собрать проект,

автоматически запустить модульные тесты и открыть визуализацию:

make run

Для очистки файлов сборки:

make clean

Структура проекта:
kmeans.h — заголовочный файл с описанием структур точек и прототипами функций.

kmeans.c — основное математическое ядро алгоритма на Си в стиле Олмана.

main.c — запуск программы,
обработка ввода параметров и пошаговый вывод кадров.

tests.c — автоматические модульные тесты для проверки корректности математики.

visualizer.py — генерация датасета через make_blobs и отрисовка графиков сравнения.

Makefile — сценарий автоматической сборки проекта.

Метрики:
Инерция (WCSS) показывает сумму квадратов расстояний от точек до центров их кластеров.
Чем ниже WCSS,
тем ближе точки к центроидам.

Силуэтный коэффициент оценивает,
насколько правильно точки сидят в своих группах.
Значение ближе к 1 означает идеальную структуру кластеров.

Индекс Дэвиса-Болдина показывает отношение разброса внутри кластера к расстоянию между ними.
Значение ближе к 0 означает максимально четкое разделение групп.

Вывод:
В проекте реализована модульная функция кластеризации K-Means++ на языке Си.
Программа позволяет наглядно подбирать оптимальное число кластеров методом локтя и оценивать качество работы алгоритма по строгим математическим критериям.
