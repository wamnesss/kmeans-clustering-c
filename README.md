# K-Means++ Clustering — Кластеризация двумерных данных

## О проекте

Данный проект представляет собой реализацию классического алгоритма машинного обучения — К-средних (K-Means) на языке C.

Модель основана на продвинутом подходе инициализации K-Means++, который решает проблему неудачного выбора стартовых центроидов за счет вероятностного распределения на основе квадратов расстояний.

Основная цель проекта:
- сгруппировать набор двумерных точек в заданное количество кластеров;
- реализовать умную инициализацию центроидов (K-Means++);
- рассчитать математические метрики качества (WCSS, Силуэт, Индекс Дэвиса-Болдина);
- визуализировать исходный датасет и результаты работы алгоритма.

# Теоретическая основа

## Что такое K-Means Clustering

Алгоритм K-Means — это метод кластеризации, в котором:
- пространство данных разбивается на K непересекающихся групп;
- каждая точка привязывается к ближайшему центру (центроиду);
- центроиды итеративно смещаются в центр масс своих кластеров;
- процесс повторяется до стабилизации (сходимости) системы.

На макроскопическом уровне этот метод позволяет находить скрытые зависимости и сегментировать датасеты.

# Алгоритм работы

Каждая итерация симуляции состоит из двух этапов:

## 1. Assignment Step (Распределение)
Точки рассчитывают расстояние до всех существующих центроидов и «привязываются» к самому близкому.

## 2. Update Step (Обновление)
Алгоритм вычисляет новые центры масс для каждого кластера на основе точек, которые в него попали, и физически сдвигает туда центроиды.

---

# Инициализация K-Means++

Вместо полностью случайного выбора всех центров:
* первый центроид выбирается случайно;
* каждый следующий выбирается с вероятностью, пропорциональной квадрату расстояния до ближайшего уже существующего центра.

Это обеспечивает:
* более быстрый поиск решения;
* защиту от попадания в локальные минимумы;
* высокую точность кластеризации.
