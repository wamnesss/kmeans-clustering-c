
# Кластеризация двумерных данных: K-Means++ и DBSCAN

## О проекте

Данный проект представляет собой реализацию классических алгоритмов машинного обучения — К-средних (K-Means) и алгоритма на основе плотности (DBSCAN) на языке C.

Модель K-Means основана на продвинутом подходе инициализации K-Means++, который решает проблему неудачного выбора стартовых центроидов за счет вероятностного распределения на основе квадратов расстояний. Алгоритм DBSCAN добавлен для решения задач со сложной нелинейной геометрией.

Основная цель проекта:

* сгруппировать набор двумерных точек в непересекающиеся кластеры;
* реализовать умную инициализацию центроидов (K-Means++);
* реализовать алгоритм DBSCAN для нахождения кластеров произвольной формы и фильтрации шума;
* рассчитать математические метрики качества (WCSS, Силуэт, Индекс Дэвиса-Болдина);
* визуализировать исходный датасет и провести наглядное сравнение работы двух алгоритмов.

# Теоретическая основа и Сравнение алгоритмов

Проект позволяет наглядно исследовать сильные и слабые стороны двух фундаментальных подходов к машинному обучению.

### 1. K-Means++ (Центроидный подход)

Алгоритм разбивает пространство на заданное число групп, привязывая точки к ближайшему геометрическому центру (центроиду).

* **Плюсы:**
* Высокая скорость работы и вычислительная эффективность.
* Идеально сегментирует данные, сгруппированные в сферические формы (облака/кучи).
* Модификация «++» защищает от неудачного случайного старта и гарантирует быструю сходимость.


* **Минусы:**
* Требует заранее указывать количество кластеров ($K$), которое часто неизвестно в реальных задачах.
* Не способен распознавать сложную нелинейную геометрию (разрезает кольца и полумесяцы на куски).
* Чувствителен к выбросам (аномальные точки смещают центры масс).



### 2. DBSCAN (Плотностной подход)

Алгоритм ищет непрерывные области с высокой плотностью точек. Кластер растет, пока соседние точки находятся в пределах заданного радиуса (`eps`) и образуют минимально допустимую группу (`minPts`).

* **Плюсы:**
* Автоматически определяет количество кластеров в данных.
* Блестяще справляется с кластерами любой геометрической формы (дуги, вложенные кольца, линии).
* Изолирует выбросы, помечая их как системный шум, а не пытаясь "притянуть" к нормальным данным.


* **Минусы:**
* Сложно кластеризует данные с разной плотностью (если один кластер плотный, а другой разреженный, трудно подобрать универсальный радиус).
* Требует ручного подбора гиперпараметров `eps` и `minPts`.

# Используемая модель

В проекте используется:

* двумерное координатное пространство (2D);
* 3 метрики вычисления расстояний;
* потоковая передача данных (stdin/stdout).

Каждая точка датасета содержит координаты (x, y), идентификатор кластера и системный флаг для графового обхода:

```c
typedef struct {
    double x;    
    double y;     
    int cluster; // Для K-Means: номер. Для DBSCAN: 0 = не определен, -1 = Шум, 1, 2... = Кластер
    int visited; // Флаг для DBSCAN: 0 = не посещена, 1 = посещена
} Point;

```

# Алгоритм работы K-Means

Каждая итерация симуляции состоит из двух этапов:

1. **Assignment Step (Распределение):** Точки рассчитывают расстояние до всех существующих центроидов и «привязываются» к самому близкому.
2. **Update Step (Обновление):** Алгоритм вычисляет новые центры масс для каждого кластера на основе точек, которые в него попали, и физически сдвигает туда центроиды.

Вместо случайного выбора всех центров применяется инициализация **K-Means++**: каждый следующий центроид выбирается с вероятностью, пропорциональной квадрату расстояния до ближайшего уже существующего центра.

---

# Визуализация

В зависимости от выбранного режима открывается графическое окно Python:

* **Режим 1 или 2 (Одиночные):** Два графика — левый (Идеальные метки от генератора) и правый (Результат работы Си-кода).
* **Режим 3 (Сравнение):** Три графика бок о бок, позволяющие наглядно увидеть разницу между истинными данными, поведением K-Means++ (центроиды отмечены `X`) и результатами DBSCAN (шум отмечен `x`). Алгоритм маппинга цветов гарантирует визуальное совпадение кластеров на графиках.

# Использование программы

После запуска команды `make run` программа предложит интерактивное меню в терминале:

1. **Выберите режим:** 1 - K-Means, 2 - DBSCAN, 3 - Сравнение алгоритмов.
2. **Введите количество точек.**
3. **Выберите форму данных:** Сферические кучи, Полумесяцы, Концентрические круги или Вытянутые полосы.
4. **Укажите параметры алгоритмов:** Количество кластеров $K$ (для K-Means) и радиус `eps` / минимум соседей `minPts` (для DBSCAN).

Скрипт сгенерирует точки нужной геометрии, передаст их в математическое ядро на C и выведет аналитику качества перед отрисовкой графиков.
